# Sports-IQ Fabric ontology

`sports_iq_ontology.yaml` is the public sport-neutral semantic contract for the
Lakehouse and Eventhouse tables generated by this repository. It intentionally
contains no Fabric item IDs or tenant-specific names.

## Import order

1. Run `azd up` or `scripts/fabric_bootstrap.py`.
2. Confirm the Lakehouse tables and Eventhouse tables exist.
3. Create a Fabric Ontology item in the generated workspace.
4. Map each YAML entity to the matching table and apply the listed
   relationships.
5. Connect the ontology or Lakehouse to a Data Agent and use the instructions in
   `fabric/data_agent/SportsIQ_FanEngagement_DataAgent.md`.

Ontology creation/import support varies by Fabric tenant and API version. The
bootstrap creates the portable data and notebook assets automatically and fails
on unsupported required APIs; ontology UI mapping remains a documented manual
step when no stable public import API is available.
